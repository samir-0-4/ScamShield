# PhantomTrace — Frontend Client

React 18 single-page application built with Vite, Tailwind CSS, React Flow, and Recharts.

---

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router v6
- **Evidence Graph**: `@xyflow/react` (React Flow)
- **Charts & Metrics**: Recharts
- **Icons**: Lucide React
- **API Client**: Axios

---

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Setup environment
cp .env.example .env

# 3. Start development server
npm run dev

# 4. Run tests
npm test

# 5. Build for production
npm run build
```
